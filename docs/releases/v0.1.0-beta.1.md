First public beta of Divit, a quiet Windows app for writing blog posts, stories and books. It was called Yazı during development.

**New in this beta**

- **Write, Review and Normal modes** (Ctrl 1 / 2 / 3). Write mode shows only your text.
- **Bring in writing:** import `.md`, `.txt` and Word `.docx` files, or a whole folder. The originals are never changed.
- **Export without extra tools:** Word, PDF and Markdown are built in. Pandoc is optional, for finer typesetting and EPUB.
- **Research:** save readable copies of web pages, highlight, take notes and quote with citations. A topic typed into the Sources box becomes a search.
- **Optional AI, off by default:** Gemini, a local model, Claude, OpenAI or a compatible service. For models without web search, add Tavily, Brave Search or SearXNG. Keys stay in Windows Credential Manager, and costs are shown.
- **Clearer AI errors:** a Gemini key without search quota or billing gets a plain explanation, with the next steps on offer.
- **English and Turkish interface.** It follows Windows by default; the writing language is set per project.
- **Seven calm themes,** plus Match Windows, all checked for WCAG AA contrast.
- **Optional daily word goal** and a days-in-a-row count. Off by default.
- **Library folder of your choice,** for example in OneDrive, moved with a verified copy.
- **Signed automatic updates** that always ask before installing. **Send feedback** and **Report a bug** in Help.

**Upgrading from a Yazı development build**

On first start your library is copied from `Documents\Yazi` to `Documents\Divit`, each file checked. The old folder is kept. API keys stored by Yazı are picked up automatically.

**Known limitations**

- The installer is not code-signed, so Windows SmartScreen may warn. Choose More info → Run anyway.
- Research, automatic backups and Publish to my site still need [Node.js 22](https://nodejs.org).
- Some messages from the app's core stay in English with the Turkish interface.

Please report problems with **Help → Report a bug**. Leave your writing out of the report; a short invented sample is enough.
